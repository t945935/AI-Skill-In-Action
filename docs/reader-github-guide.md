# 讀者 GitHub repository 使用指南

## 目的

書中每個實作都應對應到讀者 repository 的檔案，讓讀者可以下載、切換版本、執行測試，再回到書中理解設計取捨。

## Repository 欄位

- URL：<https://github.com/t945935/AI-Skill-In-Action>
- 預設分支：main（已驗證）
- 範例版本標籤：正式 tag 尚待發布；目前以候選書稿基準 commit `a126da0` 為基準
- 授權：待指定

## 讀者使用流程

1. 從書中指定的版本標籤或 commit 開始，不直接使用未驗證的最新分支。
2. 先閱讀範例目錄的 README，再執行章節列出的檢查指令。
3. 將修改放在自己的分支或複本中，保留原始範例以便比較。
4. 遇到版本差異時，記錄作業系統、工具版本與錯誤訊息。

正式 tag 與授權條款確認後，再補入本文件與各章範例說明；在此之前請勿把 `main` 視為不可變的正式版本。
