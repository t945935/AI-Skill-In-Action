# 專案角色與責任（RACI）

| 工作 | 出版者 | 主編／PM | 技術維護者 | QA／試讀者 |
|---|---|---|---|---|
| 書名、作者、版權與授權 | A | R | C | I |
| 章節內容與術語一致性 | C | A/R | C | R |
| 範例與工作流驗證 | I | A | R | R |
| EPUB、封面與版本封裝 | C | A | R | R |
| 商店價格、地區與稅務 | A/R | C | I | I |
| GitHub tag／release | I | A | R | I |
| 正式上架與發布授權 | A/R | C | I | I |
| 問題回報與棄用決策 | C | A | R | C |

R = Responsible，A = Accountable，C = Consulted，I = Informed。
