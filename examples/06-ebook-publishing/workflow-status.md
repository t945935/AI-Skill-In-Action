# 出版工作流狀態範本

每完成一個階段，就填入實際產物路徑、阻塞問題與確認人。狀態只能向下推進一格；前一格沒有證據時，不得預先填寫後續狀態。

| 階段 | 狀態 | 產物 | 阻塞問題 | 確認人／日期 |
|---|---|---|---|---|
| 內容整理 | `draft` |  |  |  |
| 編輯檢查 | `reviewed` |  |  |  |
| 範例驗證 | `buildable` |  |  |  |
| EPUB 驗證 | `validated` |  |  |  |
| 發行封裝 | `release-candidate` |  |  |  |
| 商店準備 | `ready-to-submit` |  |  |  |

填寫時保留「尚未確認」的欄位，不用猜測值代替。`release-candidate` 只代表候選包已建立並通過自動檢查；最新 EPUBCheck、裝置試讀、出版身份與平台欄位仍應在對應列留下人工確認紀錄。
