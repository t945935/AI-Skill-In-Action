# 自建 Skill 範例

本範例示範如何把「檢查單一書稿副章並產生報告」封裝成最小 Skill。它只產生建議，不會自動改寫原稿，也不會執行發布操作。

## 檔案

- [`SKILL.md`](SKILL.md)：行為契約與工作流程
- [`templates/review-report.md`](templates/review-report.md)：固定的報告格式

## 使用前檢查

1. 先盤點現成的書稿與連貫性 Skill，確認沒有重複功能。
2. 將本範例複製到目標工具支援的 Skill 目錄，而不是直接覆寫既有 Skill。
3. 依目標工具官方文件確認 front matter 欄位與資源路徑規則。

## 驗收案例

- 成功：提供存在的副章與規範，產生包含檢查範圍的報告。
- 失敗：指定不存在的檔案，回報路徑錯誤並停止。
- 失敗：要求直接覆寫原稿，拒絕修改並提出先產生差異報告的替代方案。
