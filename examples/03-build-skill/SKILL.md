# Book Chapter Review

## 何時使用

當使用者要求檢查一個副章，且已提供章節檔案與專案規範時使用。

## 不處理的工作

- 不重寫未指定的章節。
- 不刪除原稿或覆寫原始檔。
- 不代表作者發布或上傳任何檔案。

## 工作流程

1. 讀取指定章節與必要的專案規範。
2. 檢查標題層級、內部連結、術語與程式碼標籤。
3. 將問題分成阻塞與非阻塞兩類。
4. 產生報告，列出檔案路徑與建議修正。
5. 只有在使用者明確要求時才修改檔案。

## 驗收

- 報告包含檢查範圍與檢查日期。
- 每個問題都有檔案路徑與可重現說明。
- 未經授權不會改動原稿。
