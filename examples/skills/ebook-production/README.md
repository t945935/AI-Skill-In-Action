# ebook-production

- 類別：EPUB 製作與上架整合
- 用途：從原稿或既有 EPUB，整理新書／改版內容、修整窄螢幕表格、重繪概念圖、製作封面、驗證 EPUB，並準備 Google Play Books 上架資料。
- 觸發：使用者提供書名、原稿、EPUB 或 GGKEY，並要求製作、改版、修排版或準備上架時。
- 輸入：可合法使用的原稿／EPUB、封面素材、repo、出版 metadata 與明確修改範圍。
- 輸出：另存的 EPUB、封面、變更摘要、封裝與窄螢幕驗證結果；若要求上架，另附待確認欄位及實際平台狀態。
- 驗收：來源不被覆寫；修改內容與表格資料可追溯；EPUB 資源引用有效；窄螢幕預覽無水平溢出；上傳、審核與上架狀態分開報告。
- 限制：不繞過 DRM、不猜填作者／ISBN／價格／授權；公開發行、覆蓋既有版本及商業設定需明確授權。此版本尚未有獨立的失敗／安全 fixture，不列為已驗證或核心推薦 Skill。
