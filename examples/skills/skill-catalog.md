## 選讀 Skill

`publish-google-play-books`、`google-play-books-publisher`、`imagegen`、`documents`、`pdf`、`presentations` 與 `spreadsheets` 先保留為延伸案例。它們涉及外部帳號、平台權限或不同產物格式，不納入本書的最短成功路徑。

## 納入規則

納入書中主線的 Skill 必須有明確來源、版本查證欄位、授權狀態、至少一個成功案例與一個失敗案例，並能在乾淨目錄重跑。若無法取得上述證據，只能列為候選，不得寫成「推薦」或「已驗證」。

本 repository 不包裝第三方 Skill 的完整檔案；讀者應依宿主官方文件安裝，並把實際版本與日期記入自己的 inventory。
